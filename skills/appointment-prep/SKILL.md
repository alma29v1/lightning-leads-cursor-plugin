# Appointment prep

## When to use
- Upcoming appointment / demo prep
- "What do I need to know about this house?"
- Product / feature explainers for the door

## Steps
1. Call `get_appointment_prep_context` for the lead/appointment.
2. Use `explain_feature` only for Lightning Leads product questions.
3. Return a tight door script: opener, proof points, objection handles, close ask.

## Rules
- Stay inside Lightning Leads product truth from tools — no invented promotions.
